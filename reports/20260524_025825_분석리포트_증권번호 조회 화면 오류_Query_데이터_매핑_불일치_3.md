## 🔍 에러 분석 결과

### 1️⃣ 근본 원인  
1. **페이지네이션 로직 누락**  
   - `PolicySearchPSI.searchPolicies` 메서드에서는 `page`·`size` 파라미터를 받아 `policySearchDSI.searchPolicies(page, size)`에 그대로 전달하고 있지만, 실제 DB 조회 단계에서 **OFFSET / LIMIT**(또는 MyBatis‑PageHelper 등) 을 적용하지 않아 기본값(10건)만 반환됩니다.  
   - 결과적으로 전체 18건이 존재함에도 불구하고 첫 페이지(10건)만 화면에 표시됩니다.  

2. **UI‑페이지 선택 기능 부재**  
   - 컨트롤러에서 페이지 정보를 모델에 넣어 주지 않으며, 뷰(Thymeleaf)에도 페이지 네비게이션 UI가 구현돼 있지 않아 사용자가 다른 페이지를 요청할 수 없습니다.  

3. **데이터 매핑 불일치(보조 원인)**  
   - `Policy` 엔티티와 DB 컬럼 매핑이 정상이라면 18건 전체가 조회돼야 하지만, 페이지네이션이 적용되지 않아 “매핑 불일치”처럼 보일 수 있습니다. 실제 매핑 자체는 문제되지 않으며, **조회 범위 제한**이 원인입니다.

### 5️⃣ 참고용 코드 예시 (개발자가 직접 적용)

#### ① Service / DSI 레이어

```java
// PolicySearchDSI.java
@Service
public class PolicySearchDSI {

    @Autowired
    private PolicyMapper policyMapper;

    /**
     * 페이지네이션 적용된 정책 조회
     *
     * @param page 현재 페이지(1‑based)
     * @param size 페이지당 건수
     * @return 조회된 정책 리스트
     */
    public List<Policy> searchPolicies(int page, int size) {
        int offset = (page - 1) * size;
        return policyMapper.selectPolicies(offset, size);
    }

    /**
     * 전체 건수 조회 (페이지네이션 UI에 필요)
     */
    public int countAllPolicies() {
        return policyMapper.countPolicies();
    }
}
```

#### ② MyBatis 매퍼

```xml
<!-- PolicyMapper.xml -->
<select id="selectPolicies" resultType="com.hanwha.ax.psi.Policy">
    SELECT *
    FROM policies
    ORDER BY policy_id DESC
    LIMIT #{size} OFFSET #{offset}
</select>

<select id="countPolicies" resultType="int">
    SELECT COUNT(*) FROM policies
</select>
```

#### ③ Controller (PSI)

```java
@GetMapping
public String searchPolicies(Model model,
                             @RequestParam(defaultValue = "1") int page,
                             @RequestParam(defaultValue = "10") int size) {

    List<Policy> policies = policySearchDSI.searchPolicies(page, size);
    int totalCount = policySearchDSI.countAllPolicies();

    model.addAttribute("policies", policies);
    model.addAttribute("currentPage", page);
    model.addAttribute("pageSize", size);
    model.addAttribute("totalCount", totalCount);
    // 페이지 수 계산 (예: Math.ceil(totalCount / (double)size))
    model.addAttribute("totalPages", (int)Math.ceil((double)totalCount / size));

    return "policy/search";
}
```
