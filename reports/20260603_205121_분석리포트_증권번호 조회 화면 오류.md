## 4️⃣ 예방 및 품질 향상 방안  

1. **매직 넘버 제거**  
   - `10` 과 같은 하드코딩된 숫자를 `static final int DEFAULT_PAGE_SIZE = 10;` 로 선언하고, 설정 파일(`application.properties` 등)에서 오버라이드 가능하게 함.  

2. **통합 페이징 인터페이스 정의**  
   ```java
   public interface PagedResult<T> {
       List<T> getItems();      // 현재 페이지 데이터
       long getTotalCount();    // 전체 건수
       int getPage();           // 현재 페이지 번호 (0‑base)
       int getPageSize();       // 페이지당 건수
   }
   ```
   - 서비스·DAO가 이 인터페이스를 구현하도록 하면, **총 건수와 실제 데이터**가 항상 한 쌍으로 반환돼 불일치 위험이 감소.  

3. **CI/CD 파이프라인에 페이징 테스트 추가**  
   - `mvn test` 혹은 `gradle test` 단계에 **PagingTest** 클래스를 두고, 다양한 페이지·사이즈 조합을 자동 검증.  

4. **UI/UX 설계 시 “전체 보기” 옵션 제공**  
   - 페이지 사이즈를 `0` 혹은 `-1` 로 지정하면 **전체 데이터를 한 번에** 로드하도록 옵션을 두면, 사용자가 “전체 조회”를 기대할 때 바로 전체를 확인 가능.  

5. **로그 표준화**  
   - `SECURITY_INQUIRY` 라는 고유 로그 카테고리를 만들고, **시작/끝/예외** 시점에 아래와 같은 포맷으로 기록  
     ```
     [SECURITY_INQUIRY] userId=xxx, action=GET_ALL, page=0, size=10, total=18, returned=10, duration=124ms
     ```

```java
// Service
public PagedResult<SecurityDto> getAllSecurities(int page, int size) {
    long total = securityDao.countAll();               // 전체 건수
    List<SecurityDto> items = securityDao.findAll(page, size);

public List<SecurityDto> findAll(@Param("offset") int page,
                                 @Param("limit")  int size) {
    int offset = page * size;
    return sqlSession.selectList("SecurityMapper.selectAll", 
                                 Map.of("offset", offset, "limit", size));
}
```

### 6‑2. UI 화면 (페이지 네비게이션)

```java
// 화면 초기화
int pageSize = AppConfig.getInt("security.inquiry.pageSize", 10);
int currentPage = 0;

private void loadPage(int page) {
    PagedResult<SecurityDto> result = service.getAllSecurities(page, pageSize);
    tableModel.setRows(result.getItems());          // 화면에 현재 페이지 데이터 바인딩
    lblTotal.setText("총 " + result.getTotalCount() + "건");
    btnPrev.setEnabled(page > 0);
    btnNext.setEnabled((page + 1) * pageSize < result.getTotalCount());
    currentPage = page;
}

// 버튼 액션
btnPrev.addActionListener(e -> loadPage(currentPage - 1));
btnNext.addActionListener(e -> loadPage(currentPage + 1));
```

### 🔹 2순위 – **Mapper / SQL에서 limit 적용 방식을 유연하게 변경**  

- **MyBatis** 를 사용한다면 `RowBounds` 혹은 파라미터 바인딩을 이용해 limit/offset 를 동적으로 전달.  
- 기존에 `LIMIT 10` 으로 하드코딩된 경우, 아래와 같이 수정:

  ```xml
  <!-- 기존 (하드코드) -->
  <!-- SELECT * FROM policy WHERE ... LIMIT 10 -->
  
  <!-- 수정 (동적 파라미터) -->
  SELECT * FROM policy
  WHERE ${whereClause}
  ORDER BY ${orderBy}
  LIMIT #{limit}
  OFFSET #{offset}
  ```

- **전체 조회** 시 `limit` 에 `null` 혹은 큰 값을 넘겨서 제한을 없앰.

### 🔹 3순위 – **totalCount 와 resultList 를 동일한 조건으로 조회**  

- 현재 `totalCount` 가 별도 `SELECT COUNT(*)` 로 구해지고, `resultList` 가 `LIMIT` 로 제한되는 구조라면, **조건이 동일**한지 재검증.  
- `WHERE` 절, 조인, 필터링 로직이 `COUNT` 와 `SELECT` 에 동일하게 적용돼야 함.  

### 🔹 4순위 – **전역 페이지네이션 설정 검토**  

- `application.yml` 혹은 `mybatis-config.xml` 에 `default-page-size: 10` 이 정의돼 있다면, **전체 조회** 옵션을 별도 플래그(`isAll=true`) 로 처리하도록 보완.

### 5‑1. Service (PolicySearchPSI) – 페이지 사이즈 동적 처리

```java
@Service
@RequiredArgsConstructor
public class PolicySearchPSI {

    private final PolicySearchMapper policySearchMapper;

    public String searchPolicy(Model model, SearchVO searchVO) {
        // 1) 페이지 사이즈(=limit) 결정
        Integer pageSize = searchVO.getPageSize();          // UI에서 전달된 값
        if (pageSize == null || pageSize == 0) {
            // 0 또는 null → 전체 조회 (제한 없앰)
            pageSize = Integer.MAX_VALUE;
        }

        // 2) offset 계산 (pageNumber 가 null이면 1 로 간주)
        int pageNumber = (searchVO.getPageNumber() == null) ? 1 : searchVO.getPageNumber();
        int offset = (pageNumber - 1) * pageSize;

        // 3) DB 조회
        List<Policy> resultList = policySearchMapper.selectPolicyList(pageSize, offset);
        int totalCount = policySearchMapper.selectPolicyTotalCount(searchVO.getSearchCondition());

        // 4) Model 에 전달
        model.addAttribute("searchVO", searchVO);
        model.addAttribute("resultList", resultList);
        model.addAttribute("totalCount", totalCount);
        model.addAttribute("searchExecuted", true);

        log.info("[PSI] 증권조회 결과 건수: {}", totalCount);
        return "policySearch";
    }
}
```
